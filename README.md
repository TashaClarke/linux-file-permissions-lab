# linux-file-permissions-lab

## Overview
Hands-on cybersecurity lab focused on using Linux commands to inspect, interpret, and modify file and directory permissions.

## Skills Demonstrated
- Linux file and directory permissions
- Permission string interpretation
- Access control
- 'chmod' command
- Managing permissions for files, hidden files, and directories

## Key Takeaway
Strengthened my understanding of Linux access control and how proper file permissions help protect resources from unauthorized access.
